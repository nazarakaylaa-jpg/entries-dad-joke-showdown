A deterministic TypeScript program that writes one original dad joke — at most 200 characters — to `/output/entry.txt`.

The joke: *"Why did I name our dog Bacon? So every morning I can tell the kids I'm bringing home the bacon."* (95 characters)

## Run it

```sh
npx tsx main.ts
```
